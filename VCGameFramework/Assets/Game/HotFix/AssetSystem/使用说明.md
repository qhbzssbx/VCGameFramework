# VCGameFramework 资源管理系统使用说明

## 概述

这是一个基于YooAsset、VContainer和UniTask构建的高级资源管理系统，专为MMORPG等大型Unity项目设计。系统提供了完整的资源生命周期管理、对象池、地址映射、统一卸载等功能。

## 核心特性

### 🚀 主要功能
- **线程安全的资源缓存**：支持并发去重、引用计数和TTL延迟释放
- **生命周期对齐**：与VContainer的LifetimeScope完美集成
- **对象池管理**：高性能的预制体池化系统
- **地址映射**：支持多平台、多画质的资源变体选择
- **统一卸载**：智能的资源卸载策略和触发机制
- **完整观测**：详细的性能统计和调试信息

## 快速开始

### 1. 项目配置

在项目的根LifetimeScope中注册资源系统模块：

```csharp
public class ProjectLifetimeScope : LifetimeScope
{
    protected override void Configure(IContainerBuilder builder)
    {
        // 注册资源管理模块
        var assetModule = new AssetSystemModule();
        assetModule.Configure(builder);
    }
}
```

### 2. UI窗口中使用

```csharp
public class LoginWindow : MonoBehaviour
{
    [Inject] private IAssetScope _assetScope;
    [Inject] private CancellationToken _scopeCancellationToken;
    
    public async UniTask OpenAsync()
    {
        // Pin资源 - 与窗口生命周期一致
        var bgPrefab = await _assetScope.PinAsync<GameObject>("ui", "LoginBackground", _scopeCancellationToken);
        var background = Instantiate(bgPrefab, transform);
        
        // Lease资源 - 使用后自动释放
        await using var configLease = await _assetScope.LeaseAsync<TextAsset>("config", "LoginConfig", _scopeCancellationToken);
        // 使用配置...
    }
    
    // 窗口销毁时，AssetScope会自动释放所有Pin的资源
}
```

### 3. 对象池使用

```csharp
public class BulletManager : MonoBehaviour
{
    [Inject] private IAssetPoolProvider _poolProvider;
    
    private async UniTask InitializeAsync()
    {
        // 初始化子弹池
        await _poolProvider.InitializePoolAsync<BulletComponent>("effects", "StandardBullet", initialSize: 10, maxSize: 50);
    }
    
    private async UniTask FireBulletAsync()
    {
        // 从池中获取子弹
        var bullet = await _poolProvider.SpawnAsync<BulletComponent>("effects", "StandardBullet");
        
        // 使用完毕后归还
        _poolProvider.Despawn(bullet);
    }
}
```

## 最佳实践

### ✅ 推荐做法

1. **使用Pin进行长期持有**
   ```csharp
   // ✅ 窗口生命周期内持有的资源使用Pin
   var background = await _assetScope.PinAsync<GameObject>("ui", "WindowBg", ct);
   ```

2. **使用Lease进行短期使用**
   ```csharp
   // ✅ 临时使用的配置文件等使用Lease
   await using var config = await _assetScope.LeaseAsync<TextAsset>("config", "Settings", ct);
   ```

3. **高频对象使用对象池**
   ```csharp
   // ✅ 频繁创建销毁的对象使用Pool
   var bullet = await _poolProvider.SpawnAsync<BulletComponent>("effects", "Bullet", ct);
   ```

### ❌ 避免的做法

1. **不要直接使用YooAssets API**
   ```csharp
   // ❌ 避免直接调用
   var handle = YooAssets.LoadAssetAsync<GameObject>(address);
   
   // ✅ 使用资源管理系统
   var asset = await _assetScope.PinAsync<GameObject>("package", address, ct);
   ```

2. **不要忘记处理CancellationToken**
   ```csharp
   // ❌ 没有传递CancellationToken
   await _assetScope.PinAsync<GameObject>("ui", "Panel");
   
   // ✅ 正确传递CancellationToken
   await _assetScope.PinAsync<GameObject>("ui", "Panel", _scopeCancellationToken);
   ```
